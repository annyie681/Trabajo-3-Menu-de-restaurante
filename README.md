# Trabajo-3-Menu-de-restaurante
Trabajo 3 para CV - Menú de Restaurante

Creadores: Hernández Morales Anahí López Corella David Antonio Sandoval López Daniela

Descripción: Es un menú digital de órdenes para un restaurante. Permite navegar por diferentes categorías, o sea, desayunos, entradas, comidas, bebidas y postres, agregar productos, y ver el costo antes de confirmar o cancelar una orden.

Información Adicional: Creado por medio de Canva, utilizando sus herramientas para agregar audio, botones e interactividad entre los distintos escenarios del menú. Diseñado para que se vayan almacenando las órdenes conforme se escogen los platillos y se realice el pedido al finalizar el proceso..
